# 🌌 Cosmic AI Astrologer & Vedic Synastry Engine

A full-stack, multilingual astrology guidance platform powered by high-speed LLM inference and 3D WebGL graphics.

## 🚀 Features
- **3D Celestial Scene:** Built using Three.js with realistic planetary mesh, dynamic lighting, and orbital star fields.
- **Vedic Matchmaking & Horoscope:** Generates personalized readings for singles and compatibility reports for couples.
- **Multilingual Support:** Native Bengali, Banglish, Hindi, Hinglish, and English.
- **Non-blocking Architecture:** Fast LLM inference using Groq LLaMA models and asynchronous background persistence.

## 🛠 Tech Stack
- **Frontend:** Vanilla JavaScript, HTML5, Tailwind CSS, Three.js (WebGL)
- **Backend:** Python, FastAPI, AsyncGroq, Pydantic
- **Data Persistence:** Google Sheets API via Service Account
